# Maruti Electrical - E-commerce Website

Run: double-click `index.html`, or `node server.js` and open http://localhost:3000
(Internet needed for Bootstrap, Swiper, AOS, Font Awesome, Google Fonts via CDN.)

## Edit products / prices / WhatsApp number
Open `js/data.js`:
- `SITE.whatsapp` = 918485896373 (all WhatsApp buttons use this)
- `PRODUCTS` = name, price, mrp, images, description, specifications
- Add product images in `images/products/` and list the file names (without .jpg) in `imgs`.

## Pages
index, shop, product (?id=), cart, about, contact
